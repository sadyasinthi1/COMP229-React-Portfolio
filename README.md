# Sadya React Portfolio - COMP229 Assignment 1

A six-page React portfolio created to satisfy the COMP229 Assignment 1 requirements.

## Pages

- Home
- About Me
- Projects
- Education
- Services
- Contact Me

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before submitting

1. Replace `public/profile-placeholder.svg` with your own head-and-shoulders photo and update the `src` in `src/pages/About.jsx` if you use a different filename.
2. Confirm your email, portfolio and other public contact details in `src/pages/Contact.jsx`.
3. Test every navigation link and the Contact form.
4. Run `npm run build` and fix any errors before submission.
5. Commit each meaningful development stage separately in Git/GitHub.

## Suggested commit history for the assignment

Do not create all of these at once after finishing. Commit as you actually complete each stage.

1. `chore: initialize React portfolio project`
2. `feat: add navigation and shared layout`
3. `feat: build home and about pages`
4. `feat: add projects and education pages`
5. `feat: add services and contact form`
6. `style: add responsive portfolio design`
7. `docs: improve comments and project README`
8. `fix: final accessibility and build checks`
